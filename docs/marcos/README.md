# Documentos de marco

Um documento de desenho por marco (ou por pesquisa que originou marcos): objetivo, pesquisa, requisitos, decisões no formato DECISÃO/ALTERNATIVAS/TRADE-OFFS, plano e, no fim, o **STATUS** com o que foi feito e as decisões tomadas ao codar. O processo está em [Como trabalhamos](../processo/como-trabalhamos.md).

São **registros**: depois que o marco termina, o documento não é reescrito. O que continua valendo foi consolidado na documentação viva ([regras de negócio](../produto/regras-de-negocio.md), [arquitetura](../arquitetura/visao-geral.md), [ADRs](../decisoes/README.md)).

Os nomes de arquivo mantêm a numeração original (continuação do discovery, que vai de 00 a 20) porque comentários no código citam "doc 32" e "doc 33". **Não renomeie.**
